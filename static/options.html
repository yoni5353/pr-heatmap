PR Heatmap

No setup is needed: the heatmap reads pull requests with your existing GitHub login, so any PR you can open works, including private repositories where you're a collaborator.

Optionally, add a token to use the GitHub REST API instead. It handles merge commits better, so a few more lines get colored on PRs that merged their base branch in. Use a fine-grained token with read-only Contents and Pull requests access, or a classic token with the repo scope for repositories owned by another user. The token is stored in this browser only and is only sent to api.github.com.
