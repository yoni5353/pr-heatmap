PR Heatmap

Using your GitHub login.

Do I need a token?

No. Without one, PRs are read with your GitHub login, including private repos you collaborate on. With one, the GitHub API is used, which also tints edits made inside merge commits.

Use a fine-grained token with read-only Contents and Pull requests access, or a classic token with repo for repos owned by another user. It's stored in this browser and only sent to api.github.com.
